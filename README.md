# ORBIT

安装：`npm install`

本地启动：`npm run dev`

检查：`npm run typecheck`，`npm run build`。

Docker 启动：`docker compose up --build`，打开 http://localhost:8517 。

## 离线互动作品导出

右侧「06 / 离线互动作品」导出的是一个独立 HTML 单页（`orbit-<标题>-<格式>.html`）：

- 内嵌压缩后的全景照片（Data URL）、作者点击导出时的投影与边缘设置，以及标题；
- 页面自带查看器脚本与样式，不引用任何外部地址，断网双击即可打开；
- 接收者可拖动旋转、滚轮/双指缩放、切换行星与隧道、用滑杆精调，并可一键恢复作者视角；
- 键盘：方向键旋转，`+` / `-` 缩放，`P` 切换投影，`0` 恢复作者视角；
- 导出前会先给出预计体积；清晰度、格式与质量可在导出前调整，导出后显示实际大小。

查看端有两条渲染路径，画面构图一致：

| 路径 | 适用 | 特点 |
| --- | --- | --- |
| 纹理采样（WebGL） | 有显卡加速的设备 | 按设备像素比渲染，高分屏清晰 |
| 软件采样（CPU） | 无加速、WebGL 被禁用的环境 | 任意设备可拖动；交互时自动降采样，松手恢复细节 |

两条路径共用同一套逆向投影、水平环绕、垂直钳制与接缝融合公式，导出文件中的「查看引擎」可手动切换对比。照片解码失败时会显示说明与作者视角的静态预览。

发布设置与编辑器状态相互独立：导出时冻结当前构图，导出后再改编辑器不会影响已生成的文件；重新打开导出的单页会回到导出时的初始构图。

测试：`npm test`（类型检查 + 单元检查 + 离线端到端测试，端到端需要 Playwright Chromium）。
